# 手機、平板與無障礙設計審查

日期：2026-07-29

## 四個審查視角

1. 手機 UX：檢查 390px 的資訊順序、觸控尺寸、橫向溢位與回訪流程。
2. 平板 UX：檢查 768px 的欄數、卡片密度、斷點銜接與頁面長度。
3. 視覺與品牌：檢查品牌色、文字對比、標題尺度與三身份的一致性。
4. 無障礙與資訊架構：檢查主要地標、鍵盤焦點、朗讀名稱、標籤及漸進揭露。

## 已完成修正

- 移除重複的 `main` 地標，三身份都提供頁內重點導覽。
- 學生進度浮層只在學生版顯示，教師與家長頁不再被遮擋。
- 快速開始、七燈進度、平台篩選、航線選擇與隱私設定改為可收合內容。
- 教師版將主域與班級航線提前，家長版保留今日陪伴重點與快速選站。
- 390px 與 768px 的按鈕、連結及摘要控制至少維持 44px 可操作高度。
- 平板主域使用雙欄，手機與平板的平台卡縮短到約 395～403px。
- 修正快速開始按鈕低對比、焦點樣式、反思欄位標籤及外連朗讀名稱。
- 修正家長／教師切回學生版時的推薦任務資料契約錯誤。

## 驗收結果

- 自動化測試：150／150 通過。
- 390 × 844：學生、教師、家長均無水平溢位，主要操作無小於 44px 的可見目標。
- 768 × 1024：主域為雙欄；精簡平台卡約 395px；三身份均無水平溢位。
- 1280 × 900：平台卡為三欄，無水平溢位。
- 乾淨瀏覽器分頁：無 error 或 warning。
